# Cybersecurity Knowledge Lab

A practical, evidence-driven cybersecurity learning repository built around:

**LEARN → BUILD → BREAK → DETECT → INVESTIGATE → FIX → DOCUMENT**

This repository is designed to turn cybersecurity knowledge into demonstrable engineering skill across offensive security, application security, security engineering, SOC operations, detection engineering, threat intelligence, cloud security, and incident response.

## Goals

- Build strong cybersecurity fundamentals.
- Reproduce security concepts in controlled, legal labs.
- Understand both attacker and defender perspectives.
- Write detections, investigations, remediation guidance, and technical reports.
- Create interview-ready evidence for security roles.
- Keep claims backed by authoritative references.

## Learning standard

Every substantial topic should answer:

1. What is it?
2. Why does it happen?
3. How does it work technically?
4. How can it be reproduced safely?
5. How would an attacker identify or abuse it?
6. How would a defender detect it?
7. How is it remediated?
8. How would I explain it in an interview?

## Repository structure

- `00-foundations/` — networking, operating systems, Linux, Windows, cryptography
- `01-web-security/` — core web vulnerabilities and security controls
- `02-api-security/` — REST, GraphQL, JWT, OAuth, authorization, rate limiting
- `03-network-security/` — TCP/IP, DNS, HTTP, TLS, scanning, IDS
- `04-linux-security/` — Linux hardening and security
- `05-windows-security/` — Windows security fundamentals
- `06-active-directory/` — Kerberos, LDAP, NTLM, privilege escalation, attack paths
- `07-cloud-security/` — AWS, Azure, GCP, IAM, containers
- `08-application-security/` — secure coding, SAST, DAST, SCA, secrets
- `09-soc/` — logs, triage, SIEM, detection, incident response
- `10-threat-intelligence/` — OSINT, IOCs, CVEs, MITRE ATT&CK, threat reports
- `11-malware-analysis/` — static and dynamic analysis
- `12-detection-rules/` — Sigma, YARA, Suricata
- `13-tools/` — security tooling and repeatable workflows
- `14-labs/` — controlled hands-on environments
- `15-reports/` — vulnerability, incident, and threat reports
- `16-interview-preparation/` — fundamentals, technical, scenario-based, and project questions

## Safety

All offensive-security exercises must be performed only against systems the learner owns or is explicitly authorized to test. Do not use this repository to target third-party systems.

## Current status

The repository is in the foundation phase. The roadmap defines the progression from fundamentals to integrated security labs.
