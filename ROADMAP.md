# Cybersecurity Knowledge Lab Roadmap

## Phase 1 — Foundations
- Networking fundamentals
- Linux and Windows fundamentals
- HTTP, DNS, TCP/IP, TLS
- Authentication, authorization, sessions
- Cryptography fundamentals

## Phase 2 — Web Security
- SQL injection
- XSS
- CSRF
- IDOR/BOLA
- SSRF
- File upload
- Business-logic flaws

## Phase 3 — API Security
- REST and GraphQL
- JWT
- OAuth
- Authorization testing
- Rate limiting
- API misconfiguration

## Phase 4 — Enterprise Security
- Windows security
- Active Directory
- Kerberos, LDAP, NTLM
- Privilege escalation
- Attack paths

## Phase 5 — Cloud and Application Security
- IAM
- Containers
- SAST, DAST, SCA
- Secrets and dependency security
- Secure coding

## Phase 6 — SOC and Detection
- Log analysis
- Alert triage
- SIEM
- Sigma, YARA, Suricata
- Incident response

## Phase 7 — Threat Intelligence and Malware
- OSINT
- IOC analysis
- CVE research
- MITRE ATT&CK
- Static and dynamic malware analysis

## Phase 8 — Integrated Capstone
Build a controlled environment where an attack generates telemetry, detection rules create alerts, an investigation produces findings, and remediation closes the loop.

**Milestone:** every phase should produce practical artifacts, not only notes.
