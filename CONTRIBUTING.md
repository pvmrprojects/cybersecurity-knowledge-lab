# Contributing

This repository is primarily a personal cybersecurity knowledge lab, but contributions and corrections are welcome.

## Standards

- Prefer primary and authoritative references.
- Separate facts, observations, hypotheses, and opinions.
- Never fabricate technical details, CVE data, tool output, or citations.
- Keep offensive exercises within explicitly authorized environments.
- Include reproducible evidence where practical.
- Document defensive controls and remediation alongside offensive techniques.
- Do not commit secrets, credentials, malware samples, private data, or unauthorized scan results.

## Topic quality

A completed topic should connect theory to a safe lab, detection, remediation, and interview explanation.
